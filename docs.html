DiceScript guide

DiceScript answers questions like “what are my odds to hit?”, “is advantage worth it?”, or “which weapon does more damage?” — and draws the chart. You describe a roll in the editor on the left, press Run, and the chances appear on the right. You don’t need to know how to program — you’ll copy a couple of small patterns and tweak the numbers.

The fastest way in: open the playground, click Examples, pick one, and change a number. This page explains the pieces so you can write your own.

1 · Dice

Write dice the way you’d say them out loud:

You writeYou get
d6one six-sided die. (Also d4 d8 d10 d12 d20 d100…)
d6(3)three d6 rolled together (“3d6”)
d20(2)two d20
die(7)an odd-sized die (faces 1–7) — for any size not in the list
die([0, 0, 1, 2])a custom die with exactly these faces (repeat a face to make it more likely)

To mix different dice, put them in square brackets: [d8, d6, d6] is a d8 and two d6 rolled together.

2 · See the odds

display(...) draws the chart of every possible total and how likely it is. Paste this into the playground and press Run:

display({ pool: d6(3), title: "3d6" })

The part in curly braces { … } is just a list of settings: pool is the roll to chart, title is the heading. You’ll also see the average, the most likely total, and so on.

You can chart several rolls at once — just call display again:

display({ pool: d20,    title: "flat d20" })
display({ pool: d6(3),  title: "3d6 (bell curve)" })
display({ pool: d6(2).addBonus(3), title: "2d6 + 3" })

.addBonus(3) adds a flat +3. .keepHigh(1), .keepLow(1) keep the best / worst die — more on those below.

3 · Ask a question (“what are my chances?”)

Add a filter to ask whether each roll passes. The chart then splits into pass / fail and tells you the percentage:

display({
  pool: d20,
  filter: roll => total(roll) >= 15,    // did we hit 15 or more?
  title: "d20 vs target 15",
})

Read roll => total(roll) >= 15 as a plain question: “given a roll, is its total at least 15?” The word before => (roll) is just a name for “the dice that came up”; you can call it anything. total(...) adds the dice up.

For more than two outcomes, give a list of labelled categories with colors:

display({
  pool: d6(2),
  title: "attack result",
  filter: [
    { when: roll => total(roll) <= 4,  label: "weak",   color: "#ef4444" },
    { when: roll => total(roll) <= 8,  label: "solid",  color: "#facc15" },
    { when: roll => total(roll) >= 9,  label: "strong", color: "#a3e635" },
  ],
})

Each roll falls into the first category it matches. Handy building blocks for the when question:

total(roll)the sum of the dice
maxed(roll) / floored(roll)the highest / lowest single die
count(roll, v => v >= 5)how many dice are 5 or more (success counting)

4 · Common mechanics

Advantage & disadvantage

Roll two and keep the best (or worst):

display({ pool: d20(2).keepHigh(1), filter: roll => total(roll) >= 15, title: "advantage" })
display({ pool: d20(2).keepLow(1),  filter: roll => total(roll) >= 15, title: "disadvantage" })

Keep the best N (4d6 drop lowest, etc.)

display({ pool: d6(4).keepHigh(3), title: "4d6 keep best 3 (ability score)" })

Success / dice pools

Count how many dice beat a threshold:

display({
  pool: d6(6),
  title: "6d6 — number of 5s and 6s",
  filter: [
    { when: roll => count(roll, v => v >= 5) === 0, label: "0", color: "#ef4444" },
    { when: roll => count(roll, v => v >= 5) === 1, label: "1", color: "#facc15" },
    { when: roll => count(roll, v => v >= 5) >= 2,  label: "2+", color: "#a3e635" },
  ],
})

A custom roll: exploding dice

For mechanics with their own rules, define a roll with poolBuilder. Inside, when lets the roll change itself based on what it shows. Here a maximum re-rolls and adds on top:

const explode = poolBuilder(p =>
  p.when(p[0].shows(max), again => again.addDice(explode(p)))
)

display({ pool: explode(d6), title: "exploding d6" })

In plain terms: take the roll p; when its die shows its maximum (shows(max)), add another exploding roll on top. const explode = … just gives the roll a name so it can refer to itself.

You can also discard() dice — they’re shown grayed-out but no longer count. Discarding the whole roll produces a “miss” (a 0 with no result), which the chart shows as its own bar.

5 · Compare options & see how things scale

displayScaling draws a series of bars. Give it a list of options to compare:

displayScaling({
  pool: [
    { label: "d8",     pool: d8 },
    { label: "2d4",    pool: d4(2) },
    { label: "d6 + 1", pool: d6.addBonus(1) },
  ],
  title: "which deals more?",
})

Or sweep a number to see a trend — pool: n => … means “for each value n on the x-axis, this roll”:

displayScaling({
  pool: n => d6(n),
  over: { from: 1, to: 8 },              // n goes 1, 2, … 8
  filter: roll => total(roll) >= 12,
  title: "how many d6 to beat 12?",
})

Scaling charts have an avg / % toggle: avg sizes each bar by its average value (compare power), % shows the chance of each outcome (compare reliability).

6 · Over many tries

displayCumulative answers “how likely am I to succeed at least once in N attempts?”:

displayCumulative({
  pool: d6(3),
  over: { attempts: 10 },
  filter: roll => total(roll) >= 14,
  title: "chance of a big roll within N tries",
})

7 · Roll once

displayRoll shows a single random result (with a Reroll button) instead of the full chart:

displayRoll({ pool: d6(4).keepHigh(3), title: "roll an ability score" })

8 · Sliders & toggles

Add controls and the chart updates as you drag them — great for “what if?”:

const bonus = slider("bonus", { min: 0, max: 5, value: 0 })
const sides = select("die", [4, 6, 8, 10, 12], { value: 6 })

display({
  pool: die(sides)(2).addBonus(bonus),
  filter: roll => total(roll) >= 10,
  title: "tune it",
})
slider("name", { min, max, value })a number you can drag
select("name", [a, b, c], { value })a dropdown
toggle("name", false)a checkbox (on / off)

9 · Reading the code

Three small bits of punctuation appear everywhere — that’s really all the “programming” there is:

{ pool: …, title: … }a list of settings: a name, a colon, a value, separated by commas.
roll => total(roll) >= 10a question about a roll. Left of => names the roll; right of it is the test.
const name = …give something a name so you can reuse it.

Under the hood this is JavaScript, so if you do program, anything JS works (variables, Math, loops…). But you never need more than the three patterns above.
